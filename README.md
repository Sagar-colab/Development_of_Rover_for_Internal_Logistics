# 🤖 Development of Rover for Internal Logistics Applications

## 📌 Project Overview

This project focuses on the design and development of a compact robotic rover intended for internal logistics and material handling applications. The system was developed as a major academic project and aims to address challenges in confined indoor environments such as warehouses, laboratories and small scale manufacturing units through intelligent mobility and automated lifting.

## ⚙️ System Description

The rover is built on a mecanum wheel drive platform, enabling true omnidirectional movement including forward, backward, lateral, diagonal motion and in place rotation without changing body orientation. This allows precise navigation in tight spaces where conventional wheeled systems are limited.

A servo driven lifting mechanism using a lead screw assembly is integrated at the front, enabling the rover to lift and transport lightweight payloads. The chassis and mechanical components were designed using CAD tools and fabricated using lightweight materials for stability and efficiency.

## 🧠 Control & Communication

The system is controlled using an ESP32 microcontroller with WiFi capability. Firebase Realtime Database is used for cloud based communication, allowing real time remote control through a web interface. Commands for movement and lifting are transmitted wirelessly and executed with minimal latency.

## 🛠️ Technologies & Components Used

* ESP32 microcontroller
* Mecanum wheels with DC gear motors
* L298N motor drivers
* Servo motor with lead screw lifting mechanism
* Firebase Realtime Database
* CAD design and 3D printed chassis

## 🔍 Key Features

* Omnidirectional mobility using mecanum wheels
* Compact design for confined indoor navigation
* Servo operated forklift style lifting mechanism
* Real time wireless control via web interface
* Modular architecture for future scalability

## 📈 Applications

* Warehouse and inventory automation
* Smart factories and Industry 4.0 environments
* Laboratories and research facilities
* Educational robotics and prototyping
* Internal material transport systems

## 🚀 Outcome

This project demonstrates strong practical skills in mobile robotics, motion control, embedded systems and system integration. It provides a scalable foundation for future enhancements such as autonomous navigation, sensor based obstacle avoidance and vision driven logistics automation.
